# Shadow Weave Portfolio

Современное портфолио фронтенд-разработчика в киберпанк стиле.

## Технологии

Проект построен с использованием:

- **Vite** - быстрый сборщик для разработки
- **TypeScript** - типизированный JavaScript
- **React** - библиотека для создания пользовательских интерфейсов
- **shadcn-ui** - компоненты UI
- **Tailwind CSS** - утилитарный CSS фреймворк

## Установка и запуск

### Требования

- Node.js (рекомендуется использовать nvm для установки)
- npm или yarn

### Шаги для запуска

```sh
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для production
npm run build

# Предпросмотр production сборки
npm run preview
```

## Структура проекта

```
src/
├── components/     # React компоненты
├── pages/          # Страницы приложения
├── hooks/          # Пользовательские хуки
├── lib/            # Утилиты и вспомогательные функции
└── assets/         # Статические ресурсы
```

## Разработка

Проект использует Vite для быстрой разработки с hot module replacement (HMR).

Для линтинга кода:
```sh
npm run lint
```
